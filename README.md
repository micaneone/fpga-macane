# M2_scale —— M2 第一刀的上板工程（缩放：全图适配 + 真放大）

> 由 B 轨随 M2 缩放器一起搭。**工程（.al / 引脚 / 综合）由你来建**，
> 这份 README 把"加哪些文件、顶层叫什么、上板看什么"一次说清。
> 建好之后，不连板子也能先跑 `.\check_compile.ps1`（编译 + 展开自检）。

---

## 0. 一句话

在 M1 的基础上（SD 卡装图 → SDRAM → HDMI 显示），把显示从 **1:1** 升级成
**可缩放**：默认按"适配"把整张图缩进窗口，按 **KEY1** 逐档放大看细节。

---

## 1. ★ 顶层模块

```
top_m2        （文件：rtl\top_m2.v）
```

它和 M1 的 `top_m1` 同结构（PLL / SDRAM / A 的装载机 / B 的显示链 / 串口报告），
**新增的只有两处**：

1. `zoom_sel`（新模块）：把 KEY1 的档位翻译成 `step`（1/Z）和居中偏移；
2. `disp_top` 多接三个输入 `step_q16 / off_u_q16 / off_v_q16`，
   并把 M1 那个 `cmp_off` 旋钮删掉了（读口偏移现在由 `scaler_addr` 的
   行内 4 字对齐 + `line_buf` 的 `RD_*` 常数负责）。

## 2. 建工程：要加的文件

按目录加（TD 里把**整个目录**加进去最省事；`lib\video\ref_top_video.v` **除外**，
它里面有个模块叫 `top`，加进去会抢顶层 —— 这是项目红线）。

| 目录 | 加什么 |
| --- | --- |
| `rtl\` | 全部 `.v`（`top_m2.v` 是顶层） |
| `b_display\` | 全部 `.v`（**M2 新增 4 个**：`scaler_addr.v` / `zoom_sel.v` / `udiv_q16_up.v` / `bilinear.v`） |
| `a_image\` | 全部 `.v` |
| `lib\audio\` | 全部 `.v`（★ 音频 PLL `PLL_HDMI_AUDIO.v` 现在顶层要用，**它如果被标成 `AutoExcluded`，TD 会报 `instantiate unknown module PLL_HDMI_AUDIO`**，把这条属性去掉）|
| `a_image\` 新增 | ★ 2026-10-05 音频：`sdr_rd_arb.v` / `sfx_ctrl.v` / `sfx_player.v` / `top_aud.v` / `audio_arc_calculate.v` |
| `lib\hdmi\` | 全部（含 `hdmi1.4b_transmitter_core\...enc.v`） |
| `lib\sdram\` | 全部（含三个 `.enc.v` 加密核） |
| `lib\util\` | 全部 `.v` |
| `lib\video\` | 只加 `video_timing.v`（**别加 `ref_top_video.v`**） |
| `prj\al_ip\` | `PLL_0.v`、`PLL_SDR.v`（IP 已生成好，直接当源码加；`.ipc` 是它的配置） |
| `prj\` | 引脚约束 `m2_pin.adc`、时序约束 `m2.sdc` |

> `sim\` 里没有东西，不用管。
> `bilinear.v` 这一版**还没接进流水线**（横向插值要 line_buf 双读口，是下一刀），
> 但先加进工程没关系（它是干净的纯组合模块，不影响综合）。

**约束文件的两个要点**（都踩过）：

- `m2.sdc` 里的 `set_clock_groups` 必须**四块域都写全**（50 / 40 / 100+200 / 125×2）；
  少了 100/200 那一对，会报上百条假违例。本工程的 `m2.sdc` 已经补好了。
- `m2_pin.adc` 是从 M1 直接拷的，引脚没变。

## 3. 按键

| 键 | 丝印 / 引脚 | 作用 |
| --- | --- | --- |
| **KEY1** | B2 | ★ **循环缩放档**：适配 → 1× → 1.5× → 2× → 3× → 4× → 回适配 |
| **KEY3** | B1 | 装下一张图（不变） |
| **KEY2** | C1 | 软复位重来（不变） |

> 「适配」= 整张图等比缩进 800×600 窗口、居中、四周留底色（米白）。
> 对那张超大图，适配就是**缩小**（≈0.51×）；对 640×480 的小图，适配是 1.25×。

---

## 4. 串口（115200 8N1）

和 M1 一样的每 0.5 秒一帧，但**字段 29 的含义改了**：

| 字段 | 现在是什么 |
| --- | --- |
| 29 | ★ **当前缩放档 0..5**（0=适配 1=1x 2=1.5x 3=2x 4=3x 5=4x） |
| 30 | KEY1 一共按了几次 |
| 其余 | 同 M1（W=写字数、S=状态、F=帧号、flags 等） |

上板时先看 **F 在不在动**（显示链在跑）、**S 的 bit1/bit3/bit7**
（SD 就绪 / 装完过 / HDMI 锁），再看字段 29 是否跟着按键走。

★ 2026-10-05 起**字段 28 改成音频状态位图**（原来是固定 0）：

| 位 | 含义 |
| --- | --- |
| bit15 | `aud_fail`：音效装载失败 |
| bit14 | `aud_loaded`：音效已经装进 SDRAM |
| bit13 | 音频 PLL 锁定 |
| bit12 | `aud_busy`：音频还在读/放 |
| bit11 | 有音频数据流（`aud_vld`）|
| bit10 | `play_tgl` 在翻（播放命令发出去过）|
| bit9:8 | 状态机：0 等图 / 1 等待 / 2 装载中 / 3 做完 |

## 4b. 音频（2026-10-05 新加，A 轨的链）

- **谁在做**：A 轨把 `top_aud` 交出来（内部收 `sfx_ctrl` + `sdr_rd_arb` + `sfx_player`
  + `audio_arc_calculate`），B 只做接线：加音频 PLL、把**显示读口绕道**、把 6 根
  音频线接进 HDMI 核。`line_buf.v` / `sdr_arb.v` 一行没改。
- **C 轨还没接**，所以这一版由顶层**自产命令**：上电出图 → 等 1 秒 →
  **屏上米白 ≈ 音效时长**（装音效；装载期间显示整段禁读是当前唯一确认不花屏的档）
  → 图回来 + 自动播一次；之后**每按 KEY3 换图都会再播一次**。
- **SD 卡要求**：第 0 条音效 WAV = 48 kHz / 单声道 / 16 bit PCM、**连续存放**、
  **按 3 秒准备**（每条的播放长度固定 72000 字 = 3 秒，文件短了尾巴会放垃圾）。
- **听不到声音先看字段 28**：bit13 不亮 = 音频 PLL 没锁；bit14 不亮 = 音效没装进去；
  bit11 从不亮 = `sdr_rd_arb` 没读到数据；bit11 亮但没声 = 看 HDMI 显示器/音箱的音频设置。
- **资源**：这一版离线综合 **DSP 29/29 顶格、BRAM 55/64**（音频本身 0 个 DSP）。

## 5. 上板预期现象（按这个顺序看）

1. **上电**：A 自动装第 1 张图（串口 `W` 往上涨，`S` 的 bit3 亮），
   屏上出现整张图 —— 这就是**适配档（缩小/等比）**，整张图都在窗口里。
2. **按 KEY1** → 字段 29 变 1，图变 1:1；再按 → 1.5×、2×、3×、4× ——
   **放大时看到的是原图细节**（最近邻，方块感但真实），不是把已缩小的图拉大。
3. **按 KEY3** → 换下一张。不同尺寸的图（640×480 / 800×600 / 超大图）
   都应该各自按自己的尺寸适配。
4. 超大图**按到适配档**是这一刀最关键的一眼：它要读整行 1575 个像素，
   检验行缓冲扩容到 2048 之后对不对。
5. **音频（2026-10-05 新加）**：第 1 张图出来后约 1 秒，屏上会**米白几秒**（= 音效长度，
   正在把它从 SD 卡装进 SDRAM），然后图回来、**同时听到一声音效**；
   之后每按 KEY3 换图，新图出来时都会再响一次。米白那一段是**预期的**（不是 bug）。

## 6. 已知 / 注意（先看这几条）

1. **这一版是最近邻**：放大有方块感，这是预期的。双线性下一步再接。
2. **资源要盯 BRAM**：行缓冲 `LINE_MAX` 从 1024 提到 2048，BRAM 占用会明显上升。
   综合后先看 `syn_1\gate.qor` 的 ERAM 块数，**别超过 64**。
3. **`VFLIP=1`**：SDRAM 里的图现在是自下而上存的（A 的装载顺序），
   显示侧把行号翻过来 —— 和 M1 是同一处。**A 修行序之后要把它改成 0**
   （在 `b_display\win_compositor.v` 里例化 `scaler_addr` 那一行）。
4. **4 字对齐有个前提**：请求起点要 4 字对齐，要求 `src_base` 和
   `每行字数` 都是 4 的倍数。当前大槽 0 基址是 0、这几张图的宽度都满足；
   **奇数宽 / 大槽 1** 不满足，通用修法记在 `规划\B轨待改清单.md` §三。
5. **别在交付仓库里跑 `sync_from_repo.ps1`**（那是 M1_super 的脚本，会把 A 冲回老版本）。
   本工程是**独立副本**，改 RTL 改这里就行，或者从仓库同步 `b_display\`。
