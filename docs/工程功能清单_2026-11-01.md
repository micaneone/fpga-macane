# ygcom 工程功能清单

- 生成日期：2026-11-01
- 适用工程：`PRJ1024_20261031`（1024×768 定版）、`PRJ800_20261031`（800×600 定版）
- 顶层：`PRJ1024_20261031/rtl/top_m2.v`（7472 行）
- 平台：安路 EG4S20BG256，TD 6.2.1；SDRAM 2M×32（8 MB）；W25Q16（2 MB）双镜像
- 说明：本清单按**用户可见功能**逐项列出，每项附实现位置（文件:行号）便于核对；末尾附已知限制。

## 附录 C：内容卡规范

- 文件系统：FAT32，素材放根目录。
- 图片：`ADxx.BMP`，24 bit 非压缩，1~4096 像素；高度 >900 自动抽稀（901~1800 抽 2、1801+ 抽 4）。
- 字幕：`SUBxx.SUB`，800×64，24 bit BMP 容器，白底黑字，按 1 bpp 取模。
- 音乐：`musxx.WAV`，48 kHz / 16 bit / 单声道，≤5 s。
- 报警素材：`EMG*` 前缀，独立于正常播放。
- 配套关系：`ADk.BMP` ↔ `SUBk.SUB` ↔ `musk.WAV`（k 对齐），缺项留空不沿用。
- 张数：上电自动扫描统计，换卡即换数量，不改代码。

## 附录 D：已知限制

1. **65 MHz 时序未收敛**（−6.968 ns），当前 50 MHz 运行；若后续提频需先收敛。
2. **串口字段表是历史挪用产物**，`dbg_report.v` 头注释与现状不符，以 `top_m2.v:6857-6859` 为准。
3. **分辨率切换要重配置**：黑屏 0.2~0.4 s，已用 50 ms 白闪 + 开机 1.6 s 白屏遮罩，但切换本身有短暂中断。
4. **单张大图装载慢**：1536×1152 单张约 4.7 s，这是轮播从 3 s 改 6 s 的直接原因。
5. **音量/亮度只有 11 档**（0~100% 每 10%），非连续调节。
6. **字幕固定常滚动**：2026-10-21 起 SW4 改报警，字幕滚动不再可关闭（菜单只控总开关）。
7. **KEY2 端口名与丝印不一致**：RTL 端口 `key1` 对应丝印 KEY2（历史命名），查线时注意。
