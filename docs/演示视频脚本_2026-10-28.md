# 作品演示视频脚本（初赛版）

> 依据：2026 年竞赛官方《作品报告与视频拍摄》指导——视频采用「问题 → 设计（整体到局部、分模块、方案对比与研发过程）→ 场景实测」三段式；画面干净、镜头稳定、有人声旁白与字幕、避免花哨特效与杂乱 BGM；**不得出现学校名称/校徽/地图等可识别信息**。
>
> 目标：成片 3~4 分钟，1080p 或 720p，MP4，旁白清晰，字幕全覆盖。

## 五、旁白初稿（约 1050 字）

> 这是一台纯 FPGA 逻辑实现的数字标牌样机：不跑操作系统，上电 1.7 秒出图，从 SD 卡自动识别图片、字幕和音乐并循环播放。
>
> 做它的原因很直接：商场的数字标牌要无人值守地长时间播放，而常见的 CPU 或 Android 方案，成本、功耗、启动时间和长期稳定性都受软件栈牵制。我们想验证：消费级的多媒体展示，能不能用一颗国产中小容量 FPGA 纯逻辑做出来。
>
> 设计上最关键的一步，是把内容获取和显示刷新拆成两条独立轨道。A 轨负责把 SD 卡内容装进 SDRAM，B 轨只读取已经就绪的数据。配合 SDRAM 双槽和转场后台预取，把一到一点四秒的装载时间藏进转场动画里，观众看到的换图只花零点二到零点三秒。
>
> 内容卡是即插即用的：固件上电时用轻量 FAT32 引擎统计卡上有多少张图、多少条字幕和音乐，第 k 张图配第 k 条字幕和第 k 首音乐；缺配套时宁可不显示，也不沿用上一张。
>
> 要把这些塞进这颗小 FPGA 并不容易。我们把中文点阵字模搬进 BRAM，把频谱柱数组改成 LUTRAM，又给像素地址链做了多级流水重定时，最后资源压到 LUT 百分之七十三、SLICES 百分之八十五，时序收敛。
>
> 为了让样机更像真实产品，我们还做了双镜像启动：拨一下开关，下一张图就白闪一下切换分辨率；做了六行中文菜单和六位数码管；还有应急报警模式。内部状态通过三十三个字段的串口帧实时可观测，这次迭代里的八个问题都是靠它定位的。
>
> 实测下来，样机连续运行三十分钟以上，换图、字幕、音乐全部正常。这就是我们的方案：纯逻辑、低成本、免维护、内容离线可更新的数字标牌。
